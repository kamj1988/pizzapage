# Jak anulować GitHub Copilot? / How to Cancel GitHub Copilot?

## 🇵🇱 Polski

### Anulowanie subskrypcji GitHub Copilot Individual

1. **Przejdź do ustawień GitHub:**
   - Zaloguj się na https://github.com
   - Kliknij swój awatar w prawym górnym rogu
   - Wybierz **Settings** (Ustawienia)

2. **Otwórz sekcję Billing:**
   - W menu bocznym kliknij **Billing and plans** (Rozliczenia i plany)
   - Lub przejdź bezpośrednio na: https://github.com/settings/billing

3. **Zarządzaj subskrypcją Copilot:**
   - Znajdź sekcję **GitHub Copilot**
   - Kliknij **Edit** lub **Manage**

4. **Anuluj subskrypcję:**
   - Kliknij **Cancel subscription** (Anuluj subskrypcję)
   - Potwierdź anulowanie

### Anulowanie GitHub Copilot Business/Enterprise

Jeśli Copilot został przypisany przez organizację:

1. Skontaktuj się z administratorem organizacji
2. Administrator musi przejść do:
   - Ustawienia organizacji → Copilot → Manage access
   - Usunąć Twoje konto z listy użytkowników

### Ważne informacje

- Po anulowaniu, Copilot będzie działać do końca opłaconego okresu
- Nie otrzymasz zwrotu za niewykorzystany czas
- Możesz ponownie aktywować Copilot w dowolnym momencie

## 🇬🇧 English

### Canceling GitHub Copilot Individual Subscription

1. **Go to GitHub Settings:**
   - Log in to https://github.com
   - Click your avatar in the top-right corner
   - Select **Settings**

2. **Open Billing Section:**
   - In the sidebar, click **Billing and plans**
   - Or go directly to: https://github.com/settings/billing

3. **Manage Copilot Subscription:**
   - Find the **GitHub Copilot** section
   - Click **Edit** or **Manage**

4. **Cancel Subscription:**
   - Click **Cancel subscription**
   - Confirm cancellation

### Canceling GitHub Copilot Business/Enterprise

If Copilot was assigned by your organization:

1. Contact your organization administrator
2. Administrator must:
   - Go to Organization settings → Copilot → Manage access
   - Remove your account from the users list

### Important Notes

- After cancellation, Copilot will work until the end of the paid period
- You will not receive a refund for unused time
- You can reactivate Copilot at any time

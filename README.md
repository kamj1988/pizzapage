# Pizzeria Website 🍕

A simple, elegant pizzeria website built with HTML, CSS, and JavaScript.

## 📋 Features

- Responsive design for mobile and desktop
- Pizza menu with prices
- Contact information
- Modern and clean layout

## 🚀 Getting Started

Simply open `pizzeria.html` in your web browser to view the website.

```bash
# Clone the repository
git clone https://github.com/kamj1988/pizzapage.git

# Open the website
cd pizzapage
open pizzeria.html  # macOS
start pizzeria.html # Windows
xdg-open pizzeria.html # Linux
```

## 📁 Project Structure

```
pizzapage/
├── pizzeria.html          # Main HTML file
├── pizzeria_style.css     # Stylesheet
├── file.js               # JavaScript functionality
├── DialogJSON.json       # Data configuration
└── BOX_MODEL/            # Additional resources
```
